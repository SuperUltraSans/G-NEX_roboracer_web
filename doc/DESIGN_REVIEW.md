# 디자인 점검 기록 (doc/Design.md 8장)

- 도구: `@playwright/test` + `npm run shots` (`frontend/scripts/shots.mjs`), mock 모드
- 크기: 1440×900, 768×1024, 390×844 / 언어: ko, en / 시안: pitwall, poster, sensor
- 스크린샷: `design-review/<라운드>/<시안>/<페이지>-<폭>-<언어>.png` (git 제외)
- 가로 넘침은 스크립트가 `scrollWidth - clientWidth`로 자동 검사한다.

## 1라운드 (2026-10-12)

스크린샷: `design-review/round1/` (공개 5페이지 × 3크기 × 2언어 × 3시안 = 90장). 관리자 기록 입력 화면은 별도 작업 중이라 2라운드에서 찍는다.

### 1. 템플릿처럼 보이는 부분과 수정

| 부분 | 왜 템플릿 같은가 | 수정 |
|---|---|---|
| 소개 페이지 주최·후원 자리 | 같은 크기 테두리 상자 6개가 격자로 반복된다 | 상자를 없애고 위쪽 구분선 아래 한 줄로 늘어놓았다. 로고가 들어오면 같은 높이로 맞춘다 |
| 모니터링 상태 바 | 회색 둥근 패널 안에 라벨·값을 나열한 흔한 대시보드 KPI 줄 | 패널 배경을 없애고 타이밍 화면처럼 굵은 위선(`--ink-text`)과 가는 아래선으로 구획했다 |
| 피트월 진행 방식 | 첫 칸만 회색인 두 칸 테두리 상자가 비교 카드처럼 보인다 | 상자를 없애고 칸마다 위쪽 굵은 선을 둔 섹터 띠로 바꿨다. 두 번째 칸은 선을 옅게 해서 순서를 드러낸다 |

### 2. 금지 목록 위반

- **모노스페이스가 기록 표 밖에 쓰였다(피트월).** `.num` 클래스가 Plex Mono였기 때문에 일정 시각, 다음 일정 날짜, 상태 바 값까지 모노스페이스가 되었다. `.num`(고정폭 숫자, 본문 계열 서체)과 `.record`(기록 표 전용)로 나누고, 피트월에서는 `.record`만 Plex Mono를 쓴다. 리더보드와 대진 결과만 `.record`다.
- **시안을 실시간 데이터가 아닌 곳에 썼다.** 규칙 본문 링크(`--neon-ink`)와 피트월 스크롤 유도선(`--neon`/`--neon-ink`). 링크는 본문색 + 밑줄로, 유도선은 `--on-dark-dim`(어두운 면)과 `--line-strong`(밝은 면)으로 바꿨다. `doc/DESIGN_DIRECTIONS.md`의 시안 A 설명도 고쳤다.
- 그 밖의 항목(그라데이션 배경, 글래스모피즘, 이모지, 가운데 정렬 히어로 + 3열 카드, eyebrow, `→`, 가운뎃점 메타 문자열, 글리치·스캔라인·HUD 꺾쇠, SF 서체)은 화면에 없다. `3·4위전`의 가운뎃점은 데이터(라운드 이름)다.

### 3. 남색 히어로 → 흰 본문 전환

- 피트월(깔끔한 경계): 하단 페이드가 `--ink-900` 단색으로 끝나고 흰 섹션과 직선으로 맞닿는다. 탁한 띠나 1px 틈은 없다.
- 포스터(겹침): 흰 소개 블록이 히어로 하단의 남색 단색 구간(페이드 84%부터 단색) 위로 12vh 올라온다. 블록 아래로 이미지가 비치지 않는다. 390px에서는 전체 폭에 8vh 겹침이라 경계가 직선으로 보인다.
- 센서(궤적 선 연결): 주황 선이 경계를 넘으며 `--signal` → `--signal-ink`로 바뀌고 예선·본선 노드로 이어진다.

### 4. 한·영 전환

- 줄바꿈과 넘침 없음. 포스터의 영어 제목(Anybody 좁은 폭)은 390px에서 두 줄이 된다.
- 한국어 모드의 라틴 글자와 숫자는 각 시안의 라틴 서체(Anybody, Geologica)로, 한글은 짝 서체로 렌더링된다.
- mock 데이터 중 영어 값이 빈 항목(일정 장소, 규칙 본문 일부)은 한국어로 대체되어 보인다(`pickLocalized`의 의도된 동작).

### 5. 대비, 포커스, 390px 넘침

- 가로 넘침: 90장 모두 없음.
- 390px 소개(세 시안 공통): 텍스트가 차 이미지 위에 겹쳐 대비가 떨어졌다. 좁은 화면에서만 아래에서 위로 올라오는 스크림을 더했다.
- 390px 리더보드: 팀명 열이 좁아 세 줄로 접혔다. 좁은 화면에서는 차량 번호를 팀 칸 앞에 붙이고 차량 열을 숨겼으며, 랩타임 글자를 한 단계 줄였다.
- 포커스 링은 밝은 면 `--neon-ink`, 어두운 면 `--neon`(`data-surface="dark"`)으로 전역 지정되어 있다.

### 6. 이번 라운드에서 뺀 장식

후원사 자리의 테두리 상자.

### 그 밖의 수정

- 피트월 일시 숫자에 표시 굵기가 적용되지 않던 문제(`.row dd`의 500이 덮음).
- mock 일정이 "오늘 UTC 0~9시"로 고정되어 있어 시각에 따라 "다음 일정"이 사라졌다. 현재 시각 기준으로 바꿨다.
- P2: 모니터링 큰 화면 모드(`/live?display=1`)를 추가했다. 헤더·푸터를 숨기고 이 모드에서만 어두운 면 토큰을 쓴다.

## 2라운드 (2026-10-12)

스크린샷: `design-review/round2/` (공개 5페이지 + 관리자 기록 입력 × 3크기 × 2언어 × 3시안 = 108장). 1라운드 수정 전후는 같은 파일 이름으로 `round1/`과 `round2/`를 나란히 보면 된다.

### 1. 템플릿처럼 보이는 부분과 수정

| 부분 | 판단 | 처리 |
|---|---|---|
| 관리자 최근 기록 목록의 "무효 처리" 버튼 | 20행 모두 빨간 테두리라 목록이 경고판처럼 보인다 | 확인 대화상자가 이미 파괴적 동작을 막으므로 다음 라운드에서 보조 버튼 모양으로 낮추는 것을 검토한다. 이번에는 바꾸지 않았다 |

### 2. 금지 목록 위반

- 1라운드의 모노스페이스·시안 오용은 모두 고쳐졌다. 피트월에서 Plex Mono는 리더보드와 대진 결과에만 보인다.
- 관리자 화면: 장식, 그림자, 그라데이션, 이모지가 없다.

### 3. 남색 히어로 → 흰 본문 전환

세 시안 모두 1라운드와 같다. 피트월 유도선은 이제 위 `--on-dark-dim`, 아래 `--line-strong`이다.

### 4. 한·영 전환

넘침 없음. 관리자 화면 영어 문구도 모두 들어 있다(관리자 문구 408개, 한·영 키 일치).

### 5. 대비, 포커스, 390px 넘침

- 가로 넘침: 108장 모두 없음.
- 390px 리더보드: 차량 번호가 팀 칸 앞으로 옮겨져 팀명이 한 줄(두 자리 차량 번호면 두 줄)에 들어간다.
- 관리자 입력 필드와 버튼은 모두 `--control-h`(48px) 이상, 터치 대상 44px 이상이다.

### 6. 이번 라운드에서 뺀 장식

모니터링 상태 바의 회색 패널 배경.

### 그 밖의 수정

- Markdown 렌더러를 지연 로딩으로 분리했다. 첫 화면 JS가 586kB → 430kB(gzip 182kB → 135kB)로 줄었다.
- TypeScript `strict`를 켰다(create-vite 9 템플릿에서 빠져 있었다).

## 3·4라운드 (2026-10-13, 피트월 확정 후)

- 3라운드(`design-review/round3/`): 피트월 하나로 정리한 뒤의 공개 5페이지. 가로 넘침 없음.
- 4라운드(`design-review/round4/`): 글자 크기 평준화와 규칙 뷰어 적용 후의 공개 5페이지와 관리자 기록 입력(36장). 가로 넘침 없음.

### 확인한 것
- 글자 크기: 가장 작은 글자 14px 이상, 페이지 제목 최대 36px, 히어로 대회명 36px·일시 40px. 화면마다 큰 글자와 작은 글자의 차이가 좁아졌다.
- 규칙 뷰어(더미 문서: 본문 `#`·`###` 제목, Notion식 줄바꿈 칸, 7열 표, 목록, 인용, 링크):
  - 시간표의 `14:30~15:00`이 취소선이 되던 문제를 고쳤다(`singleTilde: false`).
  - 데이터를 받기 전에 목차 감시가 시작돼 목차가 비던 문제를 고쳤다(callback ref).
  - 넓은 페이지의 왼쪽 끝이 헤더 로고와 어긋나던 것을 맞췄다(왼쪽은 고정, 오른쪽으로만 넓어짐).
  - 390px에서 7열 표가 화면 폭에 눌려 글자가 세로로 쌓이던 문제를 고쳤다(칸 안은 단어 단위 줄바꿈). 라이브러리 CSS에 표 스크롤이 없어 페이지가 54px 넘치던 것도 고쳤다(`overflow-x: auto`).

### 이번 라운드에서 뺀 장식
규칙 섹션마다 있던 목차 상자 안의 번호(1. 2. 3.). 섹션 제목과 본문 제목에 이미 번호가 들어 있는 문서가 많아 겹쳤다.
